DV-PRI-N-035: A API não confere as funções do perfil nas 13 telas de Administração e Cadastros: quem só tem consulta lê e grava

Versão nova · Principal

Alta Tipo: acesso/segurança · Tela: Pontos de água; Instrumentos; Utilidades; Utensílios; Categoria de equipamento; Local físico; Conta contábil; Conta gerencial; Grupo de usuários; Funções profissionais; Notificações padrão; Configurar notificação · Classe na versão nova: Igual ao legado em essência: a rodada 3 registra "Igual (N-011, ampliado)" (a API do Principal não confere função; o DV-PRI-025 do legado já mostrava telas abrindo pelo endereço sem permissão) · Rodada: 3 (18/10/2026)

Ver a tela do erro, com as evidências

Passos para reproduzir

  1. Entrar com o usuário de teste t.consulta, cujo perfil (0.T.TESTE_CONSULTA) tem o menu só com Perfil, Profissional e Conta usuário e nenhuma ação marcada. Nenhuma das 13 telas está no menu dele.
  2. Com a sessão desse usuário, chamar pela API a leitura (GET) de pontos de água, instrumentos, utilidades, utensílios, categorias de equipamento, locais físicos, contas contábeis, contas gerenciais, grupos de usuário, funções profissionais, notificações padrão, tipos de evento e configuração de notificação.
  3. Com a mesma sessão, gravar (POST) uma função profissional e um grupo de usuários.
  4. Digitar no navegador o endereço das telas de Funções profissionais, Grupo de usuários, Contas gerenciais, Pontos de água, Notificação padrão e Configurar notificação. Passos completos: ver execucao/2026-10-18-rodada-3/confidencial-rodada-3.md, seção 1.

Esperado

A API confere a função (tela e ação) em cada rota: quem só tem consulta (ou nada) não lê as telas fora do menu e não grava.

Obtido (o que a tela ou a API mostrou)

Leitura: 200 em todas as telas listadas, com os dados (por exemplo 41 funções, 21 contas contábeis, 10 notificações padrão). Gravação: a criação de uma função profissional respondeu 201 (função de id 44, "T. CRIADA VIA CONSULTA") e a de um grupo de usuários respondeu 201 (grupo "TCONS"). Telas abertas pelo endereço abrem todas: nas listas os botões PESQUISAR e Incluir aparecem desabilitados e, no Grupo, o SALVAR aparece desabilitado; em Notificação padrão e em Configurar notificação o botão SALVAR está ativo. O que a tela mostra desabilitado não é o que o servidor impõe. A gravação das notificações não foi executada com esse usuário; que ela também passaria é inferência.

Impacto

Um usuário só de consulta pode, pela API, criar funções e grupos (que dão acesso e atribuições) e, por inferência, mudar quem recebe avisos regulatórios. Fere o controle de acesso por perfil, base da rastreabilidade de quem pode fazer o quê.
