Substância Controlada: Regras de negócio

⤓ Baixar em Word
AnáliseManual do usuárioFluxosRegras de negócioAnvisaPasso a passoIdeal

Situação da tela: Falha grave (a partir do inventário de telas do módulo)

As regras de acesso estão na seção de segurança. Ids RN-EST-nnn vêm de entregaveis/fonte/regras-de-negocio.md; RN-EST-CAD13-nnn são novas, desta página. A situação de cada regra vem dos testes citados.

ID Regra Fonte Situação
RN-EST-025 O cadastro de substância controlada é só código e descrição e é usado pelo Item. O documento de regras diz que o código não pode ser zero. 01-cadastros-de-apoio.md; substancia_controlada_ed.aspx.cs:118-122 Contradita pelo código quanto ao zero: a conferência de "0000" está dentro de um trecho desligado (comentário). Validada em parte quanto ao uso: CT-EST-016, 22/10/2026 (o Item controlado pediu o tipo e a lista veio deste cadastro: 001 D2, 002 B1, 003 C1)
RN-EST-008 Alteração e exclusão exigem justificativa e ficam no histórico; a inclusão não tem campo de justificativa. substancia_controlada_ed.aspx.cs:126; substancia_controlada_lst.aspx.cs:238 Extraída; o teste de 22/10/2026 foi em Condição de Armazenagem (CT-EST-004, 005, 007)
RN-EST-CAD13-001 O código é obrigatório, tem até 8 letras, números ou hífen, vai para maiúsculas e não é completado com zeros; nenhum valor é recusado por ser zero. substancia_controlada_ed.aspx:49; substancia_controlada_ed.aspx.cs:138; substancia_controlada_ed.aspx.cs:118-122 Extraída
RN-EST-CAD13-002 A descrição é obrigatória (até 255), vai para maiúsculas e perde espaços repetidos. substancia_controlada_ed.aspx.cs:139 Extraída
RN-EST-CAD13-003 O código é único entre os registros não excluídos; a conferência é só do programa (o banco não tem índice único). bllSubstanciaControlada.cs:19-23; dalSubstanciaControlada.cs:207-217 Extraída; a duplicidade foi vista em Condição de Armazenagem (CT-EST-003), não aqui
RN-EST-CAD13-004 Na alteração o código fica travado; com o tipo inativo, a descrição também. A alteração exige justificativa (até 255) e grava uma linha de log por campo mudado (código, descrição, ativo, empresa, lixeira). substancia_controlada_ed.aspx.cs:49; substancia_controlada_ed.aspx.cs:262-266; SubstanciaControlada.cs:121-126 Extraída
RN-EST-CAD13-005 A exclusão exige justificativa, tenta apagar de verdade e desfaz para ver se o banco recusa por chave e então só marca como excluído. A chave existe para o Item (TBL_ITEM.ID_TIPO_SUBSTANCIA). bllSubstanciaControlada.cs:107-123; dalSubstanciaControlada.cs:185-204; TBL_ITEM.sql:85 Extraída
RN-EST-CAD13-006 Só o tipo ativo é oferecido no campo "Tipo de Substância Controlada" do Item; o campo só aparece com "CONTROLE PORTARIA 344" marcado e então é obrigatório. item_ed.aspx.cs:96; item_ed.aspx.cs:238; item_ed.aspx.cs:408 Validada em parte: CT-EST-016, 22/10/2026 (obrigatório e lista vinda do cadastro); a saída da lista ao inativar não foi vista
RN-EST-CAD13-007 O tipo é só guardado e mostrado: nenhuma tela do Estoque (movimentação, saída, relatório, inventário) usa a marca "substância controlada" ou o tipo para exigir assinatura, limitar quantidade ou escriturar. Fora do cadastro do Item, o tipo só é lido pela interface de integração do Item. ItemServicoAPI.cs:42; Item.cs:19 Extraída (busca em todo o código do Estoque, 23/10/2026); ponto para validar com a área

Resultados dos testes de tela de 22/10/2026 (execucao/2026-10-22-rodada-8/resultado.md). O plano de testes é o 08-plano-de-testes.md.

CT-EST-023 Acesso sem permissão pelo endereço Não testado (fora do escopo, 22/10/2026)
