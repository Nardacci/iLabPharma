DV-EST-110 · Conversão Fornecedor recusa o mesmo código de produto em fornecedores diferentes

Alta Aberto funcional ver o defeito completo

Ligar TESTEFORN-E22 ao TESTE FARMACEUTICA (item TESTE ITEM CAD B) foi recusado com "Esse código já está cadastrado.", porque o código já existia no TESTE PJ FARMACÊUTICA LTDA.

Como reproduzir o erro, passo a passo

  1. Ligar o mesmo código do fornecedor (TESTEFORN-E22) a um segundo fornecedor TESTE, com outro item.

Esperado

O código do produto é do fornecedor: dois fornecedores podem usar o mesmo código para produtos diferentes.

Obtido

Ligar TESTEFORN-E22 ao TESTE FARMACEUTICA (item TESTE ITEM CAD B) foi recusado com "Esse código já está cadastrado.", porque o código já existia no TESTE PJ FARMACÊUTICA LTDA.

DV-EST-111 · A mudança do código do item no fornecedor não entra no Log da Conversão Fornecedor

Média Aberto norma ver o defeito completo

O código foi mudado (TESTEFORN-E22 para TESTEFORN-E22B) com justificativa ("Alteração realizada com sucesso!"); o Ver Log mostra só: Log Alteração - Conversão de Unidade do Fornecedor ; Item Dado Antigo Dado Novo Data Hora Usuário ; INCLUSÃO DO REGISTRO 25/10/2026 00:07:56 TESTE ESTOQUE DEZ ; Justificativa

Como reproduzir o erro, passo a passo

  1. Alterar o código do item no fornecedor, com justificativa, e abrir o Log; alterar sem justificativa.

Esperado

O Log mostra o código antigo e o novo, com usuário e justificativa.

Obtido

O código foi mudado (TESTEFORN-E22 para TESTEFORN-E22B) com justificativa ("Alteração realizada com sucesso!"); o Ver Log mostra só: Log Alteração - Conversão de Unidade do Fornecedor ; Item Dado Antigo Dado Novo Data Hora Usuário ; INCLUSÃO DO REGISTRO 25/10/2026 00:07:56 TESTE ESTOQUE DEZ ; Justificativa
