Inventário de telas e situação

Data: 09/10/2026 · Versão analisada: legado entregue pelo fornecedor · Base: código (5.garantia_qualidade/app), reconhecimento (00-reconhecimento.md) e os cinco fluxos (fluxos/). Nenhuma tela foi testada ainda.

Responde à pergunta "o que temos pronto e o que funciona corretamente?". Os nomes das telas são os do menu, quando o roteiro do fornecedor os traz, ou o título que a tela mostra; o menu real precisa ser confirmado (00-reconhecimento.md, ponto para validar 1).

Como ler

Situação Significado
Funciona Testada, sem desvio. (Nenhuma ainda.)
Funciona com falhas Testada; faz o que promete, com desvios médios ou baixos. (Nenhuma ainda.)
Falha grave Testada; tem desvio de gravidade alta. (Nenhuma ainda.)
Não testada Tem lógica no código e ainda não passou pelos testes. A coluna "O que o código já aponta" diz se a análise do código encontrou falhas que o teste precisa confirmar
Não abre (pelo código) Tem lógica, mas o código aponta para uma página que não existe
Protótipo Só o desenho da tela, sem gravar nem ler dados

Das 45 telas com lógica, 35 já têm falhas apontadas pela leitura do código e 1 nem abre; 22 das 67 telas são só desenho. Os testes vão mudar a situação das telas não testadas, começando pelos casos de prioridade de cada fluxo.

Diferença em relação ao reconhecimento: lá a Exigências da ANVISA foi contada entre os 23 protótipos, porque a página que existe é só desenho. Aqui ela aparece como "Não abre", porque tem controlador com lógica apontando para uma página que não existe. São 22 protótipos e 1 tela quebrada.
