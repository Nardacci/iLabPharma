Regras de negócio

⤓ Baixar em Word

Introdução

Este documento consolida as regras de negócio do módulo Principal do LabMedSys. Ele é a base para a equipe de negócio validar o comportamento esperado e para os desenvolvedores implementarem a nova versão.

As regras vêm de quatro fontes:

  • Documento de análise v1.0 do módulo Principal (análise funcional das telas);
  • Código-fonte do sistema atual (versão 3.5.1), com a indicação do arquivo de origem;
  • Testes nas telas realizados no ambiente de teste em três rodadas: 05/10/2026 e 06/10/2026 (78 casos) e 26/10/2026 (140 passos: 48 passaram, 40 com ressalva, 33 falharam e 19 bloqueados);
  • Páginas por tela (cinco por tela, nas 32 telas do módulo): as regras de cada tela estão consolidadas na seção "Regras por tela".

Cada regra traz a sua situação depois dos testes:

Situação Significado
Validada O teste confirmou que o sistema cumpre a regra.
Validada em parte O sistema cumpre a regra, com ressalva descrita.
Diferente O sistema não cumpre a regra como esperado. O desvio (DV-PRI-nnn) descreve o que foi visto.
Não testada A regra ainda não foi verificada nas telas.
Decisão Regra definida pelo responsável do negócio.

Como usar este documento na nova versão

  • Regra Validada: manter o comportamento.
  • Regra Diferente: implementar o comportamento descrito na regra, e não o atual. O desvio indica o erro a corrigir.
  • Regra Não testada: confirmar com o negócio antes de implementar.

Regras gerais do módulo

As regras desta seção valem para todo o sistema, porque o módulo Principal controla o acesso e o histórico de todos os módulos.

Acesso ao sistema (login)

O login é feito por um serviço central do Principal, usado por todos os módulos. As verificações acontecem na ordem da tabela; a primeira que falhar interrompe o acesso.

RN-PRI-002 Usuário inexistente ou excluído não entra. Código Validada ("O usuário informado é inválido!")
RN-PRI-003 Usuário com a conta inativa não entra. Código Validada ("A conta do usuário informado está inativa!")
RN-PRI-004 Usuário inativo não entra. Código Validada ("O usuário informado está inativo!")
RN-PRI-005 O usuário só entra dentro do período de validade da conta (data inicial e final). Código Validada (antes do início e depois do fim: "A data de validade do usuário informado não permite o acesso ao sistema!")
RN-PRI-006 Após 4 senhas erradas seguidas, o usuário é bloqueado; bloqueado, nem a senha certa entra. Código Validada
RN-PRI-007 A cada senha errada, o sistema informa quantas tentativas restam. Código Diferente: mostra 4, 3, 2, 1 e bloqueia no 4º erro (DV-PRI-016)
RN-PRI-008 Login com sucesso zera o contador de tentativas. Código Validada

RN-PRI-010 Toda tentativa de acesso é registrada (usuário, data, resultado). Código Não testada pelas telas (nenhuma tela mostra o registro; depende do DBA)

RN-PRI-072 A mensagem de recusa não pode revelar se o usuário existe. Requisito da nova versão Diferente: mensagens distintas para usuário inexistente e senha errada (DV-PRI-015)

RN-PRI-028 A senha provisória vale por 5 dias e exige troca no primeiro acesso. Código Validada
