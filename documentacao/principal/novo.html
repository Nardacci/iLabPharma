Acesso ao sistema

Acesso ao sistema: entenda o menu (versão nova)Comece por aquiAcesso ao sistema: visão geral (versão nova)Comece por aqui
1LoginTela de entrada. Pede usuário e senha, conta tentativas erradas e bloqueia o usuário no limite. Tem o atalho "Esqueci minha senha" (só pede o usuário; foi aberto, não usado).Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
2Troca de senhaTela de troca obrigatória de senha. Só abre para quem entrou com senha provisória ou redefinida; com a troca pendente, nenhuma outra tela abre.Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
3SairEncerra a sessão: o menu do usuário tem a opção Sair, que chama o encerramento no servidor, limpa os dados do navegador e volta ao login. Tela equivalente no legado: sair/default.aspx (Funciona com falhas: não encerrava os outros módulos, DV-PRI-020).Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
4Sessão expirada e acesso negadoQuando a sessão expira, ou quando se abre uma tela sem estar logado, o sistema volta ao login. Não há uma tela própria de "sessão expirada" nem de "acesso negado" como no legado (erro/sessaoExpirada.aspx e erro/acessoNegado.aspx, que funcionavam). O acesso negado por falta de função é tratado só pelo menu (a tela some); o servidor não confere a função (N-011, N-035).Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
5Início e menuDepois do login, a tela inicial mostra o menu do módulo Principal. O menu é montado pelas funções do perfil: o administrador de teste vê 23 itens (Administração 7, Cadastros 14, Tabelas de apoio 1 e a entrada do sino); 22 abrem uma tela com pesquisa e lista, e só Microservices é provisória. Tela equivalente no legado: inicio.aspx, Menu.aspx e menu_nivel3.aspx (Funciona com falhas; o link do módulo Patrimônio apontava para o próprio servidor, DV-PRI-018).Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
6Notificações do usuárioO sino do cabeçalho mostra quantas notificações estão pendentes de leitura para o usuário e abre a lista (a tela completa é "Notificações do sistema", do menu Administração). Tela equivalente no legado: notificacoes.aspx e notificacao/default.aspx (Funciona com falhas).Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa

1PerfilCadastro dos perfis de acesso: cada perfil é um conjunto de funções (telas e ações) que dá permissão ao usuário. A conta do usuário recebe um ou mais perfis.Análise · Manual do usuário · Fluxos · Regras de negócio · Anvisa
