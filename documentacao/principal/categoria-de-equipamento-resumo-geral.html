Categoria de equipamento: resumo geral

Menu: Cadastros · Situação na versão nova: Ainda não testada · Tela equivalente no legado: administrativas/categoria_equipamento_lst, _ed, _rel (Não testada)

Em uma olhada

Esta tela ainda não foi testada na versão nova. O que se sabe é só o que a tela mostra ao abrir e o que o sistema entregue tinha.

O que a tela faz

Tela do menu Cadastros que abre com lista e pesquisa na versão nova.

  • Na versão nova a tela abre e lista, sem erro de API (reconhecimento da rodada 1). Nada além disso foi testado.
  • Legado: Não testada.

Para quem desenvolve

  • Sem achados: a tela ainda não foi testada. Os desvios já conhecidos do legado para telas de cadastro (DV-PRI-007 descrição repetida, DV-PRI-008 pesquisa sem acento, DV-PRI-009 exclusão sem justificativa) são o ponto de partida da conferência.

Para quem testa (QA)

  • Use o roteiro padrão de cadastro (aba Passo a passo). Registros de teste começam por T.; use o perfil 0.T.TESTE_ADMIN ou 0.T.TESTE_CADASTRO.

Para a gestão

  • Ainda sem resultado. Entra na próxima frente de testes do Principal.
