Microservices: Manual do usuário

Situação da tela: Falha grave (a partir do inventário de telas do módulo)

Antes de começar

Esta tela é para a TI. Ela abre sozinha as verificações, e cada abertura faz chamadas de rede para cada módulo, o que pode demorar. Se um serviço estiver parado, a linha dele demora a carregar.

Ler o painel

  • Passo 1. No menu Administração, abra Microservices. A tela mostra uma tabela com uma linha por módulo ativo conhecido.
  • Passo 2. Colunas: MÓDULO (nome, com link para a página de teste da API), VERSÃO (versão do módulo gravada no Principal), ENDEREÇO : PORTA (endereço do serviço, com link), MICROSERVICE (executa um "ping": ON em verde ou OFF em vermelho), MICROSERVICE CS (compara as strings de conexão do sistema web do Principal com as do serviço: OK em verde; se houver diferença, aparece o link ERROR que abre a janela "LISTA DE ERROS") e MICROSERVICE BD (testa o acesso ao banco pelo serviço: OK ou ERROR) (microservice_ed.aspx:48-53).
  • Passo 3. Se algo estiver em OFF ou ERROR, avise o desenvolvimento. A tela não diz a causa, exceto na lista de diferenças das strings de conexão.

O que a tela não faz

  • Não altera endereços, versões nem conexões.
  • Não guarda resultado nem histórico das verificações.
  • Não mostra os módulos Garantia da Qualidade, Controle de Documentos, Comercial e OPE.
  • Não explica por que um serviço está em OFF.

Campos da tela

A tela não tem campos de entrada. Só tem uma tabela de leitura.

Coluna na tela Tipo Obrigatório O que mostra Fonte
MÓDULO Texto com link Não se aplica Nome do módulo; o link abre a página de teste da API do serviço microservice_ed.aspx:48; microservice_ed.aspx.cs:48-49
VERSÃO Texto Não se aplica Versão do módulo gravada na tabela de módulos do Principal microservice_ed.aspx:49; microservice_ed.aspx.cs:51-53
ENDEREÇO : PORTA Texto com link Não se aplica Endereço do serviço, lido da configuração do servidor; o link abre a página de teste microservice_ed.aspx:50; microservice_ed.aspx.cs:55-57
MICROSERVICE Texto colorido Não se aplica ON (verde) se o serviço responde; OFF (vermelho) se a chamada falha microservice_ed.aspx:51; microservice_ed.aspx.cs:59-61 e 78-90
MICROSERVICE CS Texto colorido ou link Não se aplica OK se as strings de conexão coincidem; ERROR (link) abre a lista de diferenças microservice_ed.aspx:52; microservice_ed.aspx.cs:63-65 e 104-142
MICROSERVICE BD Texto colorido Não se aplica OK se o serviço acessa o banco; ERROR se falha microservice_ed.aspx:53; microservice_ed.aspx.cs:67-69 e 91-103

Botões e ações

Botão ou ação Quando aparece O que faz Para onde leva Fonte
Link do nome do módulo Em toda linha Abre a página de teste da API do serviço em outra aba Fora do Principal microservice_ed.aspx.cs:40 e 48
Link do endereço Em toda linha Abre a página de teste do serviço em outra aba Fora do Principal microservice_ed.aspx.cs:41 e 56
Link ERROR da coluna CS Quando as strings diferem Abre a janela "LISTA DE ERROS" com as diferenças numeradas e o botão para fechar Não muda microservice_ed.aspx.cs:116-136

A tela não tem botões de gravação, VOLTAR, Pesquisar, Imprimir nem Log.

Mensagens do sistema

Mensagem (texto exato do código) Quando aparece Fonte
ON / OFF Resultado do ping do serviço microservice_ed.aspx.cs:84 e 88
OK / ERROR Resultado do teste de banco e da comparação das strings de conexão microservice_ed.aspx.cs:97, 101, 117 e 140
LISTA DE ERROS Título da janela aberta pelo link ERROR; traz as diferenças numeradas microservice_ed.aspx.cs:130

Não há mensagem de erro de página: qualquer falha de chamada vira OFF ou ERROR, sem motivo (microservice_ed.aspx.cs:86-89, 99-102 e 138-141).
