Situação da tela: Funciona com falhas (a partir do inventário de telas do módulo)

Este manual ainda não tem capturas de tela

O passo a passo está descrito em texto, a partir do código e dos testes. As imagens das telas serão acrescentadas quando forem feitas; até lá, use também o botão Passo a passo desta tela, quando houver.

Antes de começar

O arquivo sempre nasce ligado a uma revisão de modelo. Se o modelo não existe, cadastre-o antes em GED › Modelos. Para ver arquivos de outros setores, é preciso ser do setor do modelo (ou de setor acima dele) ou ter a função de administração.

A lista

  • Passo 1. No menu, abra GED › Arquivos. A tela mostra o quadro "Pesquisa", com dois blocos, Modelo e Arquivo, e uma lista vazia ("A pesquisa não retornou nenhum resultado.", visto na captura do CT-DOC-046).
  • Passo 2. Bloco Modelo: Tipo Documento (só tipos com GED), Código Modelo, Título e Revisão (só números).
  • Passo 3. Bloco Arquivo: Chave (igual, sem diferenciar maiúsculas), Descrição (contém), Setor Responsável, Status (Todos, Em andamento, Concluído), Data de Criação e Data de Validade (de e até; só filtram quando as duas datas são preenchidas).
  • Passo 4. Clique em Pesquisar. A lista traz Tipo Documento, Cód Modelo, Título Modelo, Rev, Chave, Descrição, Criação, Validade, Setor Responsável e Status, com os ícones Editar, Excluir e Visualizar.
  • Passo 5. Limpar esvazia os filtros e esconde a lista. Esta tela não tem Imprimir nem Ver log: os dois estão desligados no código (ArquivoIndex.js:63-65; Ged:1429).
  • Passo 6. Para guardar um arquivo novo, clique em Incluir (link acima da lista, só com a função INCLUIR de DOCARQUIVO). Os passos seguintes estão na tela 02.

Atenção

  • Um arquivo concluído não mostra o lápis nem a lixeira, mas o sistema não impede a edição ou a exclusão por quem abrir o endereço (ver Falhas).
  • O filtro de Data de Criação usa a data técnica do registro, que é regravada a cada edição (ver Falhas), e não a "Data Criação" que a pessoa digitou no formulário.
  • A lista mostra os arquivos de qualquer situação do modelo, inclusive de revisões substituídas.
